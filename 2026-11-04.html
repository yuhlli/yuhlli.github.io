今日は Non-Aristotelian Logic に関するこれまでの議論を振り返り、 特に Turing Machine と命題の分解について考えた。

1. A Priori と基底の相対性

群論の実験では、単位元の存在、結合律、逆元の存在という 3つの公理を基底として定めた。

しかし、この基底は絶対的なものではない。 今回の実験において、わたしたちが恣意的に設定したものである。

同様に、a priori system も人間にとっては絶対的に見えるかもしれないが、 Non-Aristotelian Logic の立場では相対的に設定されるものである。 a priori は人間にとっての分解不可能対象であって、 絶対的な真理の根拠ではない。

2. Machine と素因数分解

自然数を素因数分解するとき、素数は分解の停止点となる。 このとき、素数であることを定義する論理式として Gödel の Prime(x) に注目した。

今回の構想では、Prime(x) を基底の定義として参照する。 重要なのは、素数判定と素因数分解が異なる操作であること、 そして基底の定義と分解規則を区別することである。

群論の命題についても、基底を定めたうえで、 入力された命題を基底に向かって分解する Machine を考える。

3. 群論による実験

入力する命題：

(a-1)-1 = a

分解の例：

(a-1)-1 = (a-1)-1 · e

= (a-1)-1 · (a-1 · a)

このように、群の公理を用いて対象を段階的に変形する。 ただし、どのような分解規則を採用するか、 また各経路がどのように基底へ到達するかは、 今後さらに定式化する必要がある。

4. 分解経路と判定

Machine の判定とは、基底まで到達する分解経路が存在するかどうか、 という問題として考えられる。

分解経路が存在すれば YES、存在しなければ NO を返す。 ただし、経路が見つからないことと、経路が存在しないことは異なる。 有限時間で判定するためには、停止性についても考える必要がある。

また、分解規則の一意性は本質的ではない。 120 を素因数分解するとき、最初に 2 で割るか 3 で割るかは、 最終的な素因数分解に影響しないからである。

5. 今後の問題

  • 命題に対する分解規則をどのように定義するか。
  • 分解経路の存在性をどのように判定するか。
  • Machine の停止性をどのように保証するか。
  • 既存の自動定理証明や計算可能性理論とどう関係するか。
  • 基底を変更したとき、分解構造はどう変化するか。
基底は絶対的な真理の根拠ではなく、 ある体系において相対的に定められる分解の停止点である。

This is an ongoing investigation.

Note

私は人間 (やこの宇宙の秩序を把握している思考体) の認識の限界と, 広義的な Turing machine の限界が一致するような model を考える. この広義の Turing machine をこの後仮に Logical Machine (LogM) と呼ぶ.

task として私は自動証明機械を理解しなければならない. LogM はさしあたりそういった自動証明機械に近いものと考えるが, 既存の自動証明機械と異なる点として, どこでそれが停止するかを恣意的に定めることができる. たとえば自動証明機械は現在の数学で認められている推論 (Modus Ponens や Generalization) を使い, 現在の数学の公理まで到達したところで停止するが, LogM はそれが何を使いどの点まで到達すれば停止するかを私たちが決める. その理由は真理が相対的であるという私の姿勢にある.

この宇宙 (地球) の真理やそれに向かう論理は私のこの姿勢における基点としてある. 全てを相対化してしまうと何も語れなくなってしまうからである. この基点 (Top$_*$ の基点を想像している) においての LogM を LogM$_0$ とする. つまり LogM$_0$ は既存の自動証明機械と同じである.

LogM$_0$ が与えられた命題を論理的に分解するとき, 停止するのはそれが普通の数学の公理に辿り着いたときであり, それらを以後仮に基底と呼ぶ. すなわち LogM$_0$ はその基底として普通の数学の公理を持つ. 一般の LogM は別の基底をもつし, 基底に辿り着くまでの命題の因果分解の方法も異なる.

この ‘因果分解’ という語に関連していうと, それは (Aristotle 的に) ある自然数の素因数分解と似た構造をもつ. たとえば与えられた自然数は素数というそれ以上分解のできない数にまで分解されるが, LogM$_0$ も与えられた命題の因果をそれ以上説明できないような命題=通常公理と呼ばれるものまで分解される. 注意しておくべきなのはこの algorithm の考え方でさえ, Aristotle 的であることである.

例として群論の命題を考える. 群論的な命題, たとえば $(a^{-1})^{-1}=a$ が与えられたとき, 私たちはそれを群論の公理まで分解することでその真偽を得る. 記号の雰囲気としては, 群論の自動証明機械は $\mathrm{LogM}_0^{\mathrm{Grp}}$ である. このとき与えられた命題 $(a^{-1})^{-1}=a$ は与えられた自然数に相当し, その証明において現れる命題が約数に相当し, そして群の公理が素数と対応する. したがって (Aristotle 的に) LogM$_0$ やその部分機械を考察するときには, Gödel の考えのように, 基底とする対象を述語 Prime$(x)$ で定義したり, 素因数分解判定述語を論理へと拡張することとなる. 素因数分解の algorithm が自動証明機械の基礎的な構造となる.

この段落はもっと後に書くべきかもしれないが, メモとして残す. 上で述べたことは与えられた命題を ‘下へ’ 分解することだった. 逆に, ある公理系から ‘上へ’ 育てることも考えることができる. たとえば群の 3 つの公理 (と推論) を使って命題を生成するのである. 自然とこれは module のような様相となる. 演算がおそらく Heyting 代数と Modus Ponens + Generalization であることは予想できるが, たとえば係数は何であるかはまだはっきりとはわからない. しかし, 命題を生成するとき, ある基底を指定することが基本であり, そのため上で ‘基底’ という用語を使った.

与えられた命題の因果分解において, ある step から次の step へと移る方法が自然であるだろうか, という問題はある. もしそれが簡単ならば数学は計算にすぎない. 事実はそうでなく, それが困難であることは明らかである. たとえば先の命題 $(a^{-1})^{-1}=a$ を証明する過程で, $(a^{-1})^{-1}=(a^{-1})^{-1}\cdot e$ という操作を行うが, ‘なぜそのような過程が思いつくのか’ は簡単には説明できない. 素因数分解のプロセスと因果分解の違いはこの困難にある. ただし, 素因数分解よりもたんなるかけ算の方が簡単なように, ある命題の因果分解よりも先ほど述べた module の計算による到達の方が簡単であるから, この ‘上へ’ の姿勢は意味があるだろう. ‘2 を 二回, 3 を一回, 5 を一回かけたものは 60 である’ という情報を持っていれば, 60 の素因数分解は楽になる. もちろん素因数分解の一意性がここにおいて決定的ではあるが, ある論理基底を組み合わせたものとしてこの命題 $P$ が得られるという情報を持っていれば, $P$ の因果分解は容易となる.

再びの注意として, この素因数分解との関連性そのものも Aristotle 的なものであり, 一般の LogM では通用しないということがある. 地球の周囲で成り立っているものが遠い宇宙でも当然であることはないだろうという点と, しかしそうはいってもまず地球に生を受けなければそのことも考えられないという点を注意したい.
