今日は Non-Aristotelian Logic に関するこれまでの議論を振り返り、 特に Turing Machine と命題の分解について考えた。

1. A Priori と基底の相対性

群論の実験では、単位元の存在、結合律、逆元の存在という 3つの公理を基底として定めた。

しかし、この基底は絶対的なものではない。 今回の実験において、わたしたちが恣意的に設定したものである。

同様に、a priori system も人間にとっては絶対的に見えるかもしれないが、 Non-Aristotelian Logic の立場では相対的に設定されるものである。 a priori は人間にとっての分解不可能対象であって、 絶対的な真理の根拠ではない。

2. Machine と素因数分解

自然数を素因数分解するとき、素数は分解の停止点となる。 このとき、素数であることを定義する論理式として Gödel の Prime(x) に注目した。

今回の構想では、Prime(x) を基底の定義として参照する。 重要なのは、素数判定と素因数分解が異なる操作であること、 そして基底の定義と分解規則を区別することである。

群論の命題についても、基底を定めたうえで、 入力された命題を基底に向かって分解する Machine を考える。

3. 群論による実験

入力する命題：

(a-1)-1 = a

分解の例：

(a-1)-1 = (a-1)-1 · e

= (a-1)-1 · (a-1 · a)

このように、群の公理を用いて対象を段階的に変形する。 ただし、どのような分解規則を採用するか、 また各経路がどのように基底へ到達するかは、 今後さらに定式化する必要がある。

4. 分解経路と判定

Machine の判定とは、基底まで到達する分解経路が存在するかどうか、 という問題として考えられる。

分解経路が存在すれば YES、存在しなければ NO を返す。 ただし、経路が見つからないことと、経路が存在しないことは異なる。 有限時間で判定するためには、停止性についても考える必要がある。

また、分解規則の一意性は本質的ではない。 120 を素因数分解するとき、最初に 2 で割るか 3 で割るかは、 最終的な素因数分解に影響しないからである。

5. 今後の問題

  • 命題に対する分解規則をどのように定義するか。
  • 分解経路の存在性をどのように判定するか。
  • Machine の停止性をどのように保証するか。
  • 既存の自動定理証明や計算可能性理論とどう関係するか。
  • 基底を変更したとき、分解構造はどう変化するか。
基底は絶対的な真理の根拠ではなく、 ある体系において相対的に定められる分解の停止点である。

This is an ongoing investigation.
